Predict whether an airline passenger is satisfied or neutral/dissatisfied.

## Dataset
Airline Passenger Satisfaction (Kaggle):
https://www.kaggle.com/datasets/teejmahal20/airline-passenger-satisfaction

2- feature_selection_and_visualizations.ipynb
